DECISION LOGICWHY A PROCESS SHOULD BE AUTOMATED, AUGMENTED OR LEFT MANUAL
01 · REPETITIVE + RULE-BASED

If the task has clear rules, high volume and predictable inputs, automation usually creates the strongest efficiency gain.

Example: CV parsing, interview reminders, document checks.
02 · CONTEXT + AMBIGUITY

If the task requires interpretation, exceptions or relationship judgment, AI should support the human rather than replace them.

Example: validating shortlist fit for an unusual role.
03 · HIGH CONSEQUENCE

If a decision materially affects a person, keep accountable human ownership even when AI prepares evidence.

Example: final hiring decision or sensitive candidate communication.
04 · LEARNING POTENTIAL

A useful augmented task can generate evidence that later makes part of the process safe to automate.

Example: recruiter overrides become feedback for model improvement.

02 · TEMPORAL SCALE — THE PROCESS CHANGES OVER TIME

Augmentation → Automation → Environmental / organizational change → Augmentation / recalibration → possible re-automation. The point is not to choose one mode forever. A task can migrate between modes as knowledge, criteria and conditions change.

03 · SPATIAL SCALE — ONE DECISION CREATES RIPPLE EFFECTS

Task → employee role → HR function → organization → labour market. Automating candidate screening, for example, changes recruiter work, capability requirements, governance and eventually the broader skill structure of recruitment.
